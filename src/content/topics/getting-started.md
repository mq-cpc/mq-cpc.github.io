Competitive programming is a mind sport where participants write code to solve 
algorithmic puzzles under a time constraint. 
However, don't let the word 'competitive' scare you, because even if you have
no desire in competing, you can still participate in our activities to:

1. Learn algorithms and problem-solving techniques. The more problems you see, 
the better you get at recognising what they are and how to solve them. 
2. Get better understanding of the programming language that you use. You will gain experience
in writing efficient code
using libraries and advanced features that you may not come across in your classes. 
3. Gain confidence in technical interviews. The questions in these interviews are exactly
the kind that you see in competitive programming.

You don't have to be an expert to start. 
If you have an interest in solving puzzles and writing code, you may find that
competitive programming is a fun way to learn. 

You can follow the video tutorials listed below to help you get started. 

## Kattis and Java

Our platform of choice is [Kattis](https://open.kattis.com), which has a vast collection of 
problems written in the spirit of competitive programming.
Start by making an account, then try the problems listed below.
They are designed to teach you input/output handling, which is the first thing you need
to master in doing these coding questions.

We use Java in the video tutorials since that is the main language taught 
at Macquarie University, but Kattis supports
a large number of languages, so pick whichever one you are most comfortable with.
