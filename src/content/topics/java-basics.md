Contest problems arrive as text on standard input and are judged on the text
you print to standard output, so the first real skill is reading input cleanly
and producing output fast enough.

This topic covers `Scanner` and the `next()`/`nextLine()` trap that catches
everyone once, splitting and processing strings, the collections you will reach
for constantly — `ArrayList`, `HashSet`, `HashMap` — and `StringBuilder`, which
is the difference between passing and timing out on output-heavy problems.

By the end you should be able to take a straightforward problem statement and
turn it into working Java without fighting the language.
